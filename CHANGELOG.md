# Changelog

## 0.1.0

- Initial TypeScript ESM package structure.
- Added a REST client with Discord API error objects and initial rate-limit handling.
- Added Gateway identify, heartbeat, resume and reconnect foundations.
- Added slash command registration and basic interaction routing.
- Added interaction response helpers and basic builders.
- Added an in-memory LRU/TTL cache.
- Added tests, examples and npm package metadata.
- Voice protocol and Redis adapter are not implemented in this release.
